게임을 하거나 만들다가 생긴 질문을 수학과 알고리즘 모델로 바꾸고, 시뮬레이션으로 확인한 과정을 기록한다.

## 글의 종류

- **Experiments**: 문제 정의, 가정, 접근, 결과, 결론 순서의 실험 노트
- **Analysis**: 앱, 게임, 웹 서비스를 관점을 정해 분석한 글
- **Notes**: 짧은 메모와 회고

## 글 쓰는 법

새 글은 스크립트로 만든다.

```bash
npm run new -- experiment dbd-chase-math
```

글 상단의 설정 값은 이런 모양이다.

```yaml
title: "제목"
status: 진행중
draft: true
```

`draft: true`인 글은 개발 서버에서만 보이고 배포 빌드에서는 빠진다.
