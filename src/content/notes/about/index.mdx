앱과 게임을 가져와 설계 관점에서 분석한다. 어떤 문제를 어떤 구조로 풀었는지, 왜 그렇게 설계했는지를 뜯어보고, 필요하면 수학과 시뮬레이션으로 확인한 과정까지 기록한다.

## 글의 종류

- **Analysis**: 앱, 게임, 웹 서비스를 설계 관점에서 분석한 글
- **Experiments**: 문제 정의, 가정, 접근, 결과, 결론 순서의 실험 노트
- **Notes**: 짧은 메모와 프로그래밍 기록

## 글 쓰는 법

새 글은 스크립트로 만든다.

```bash
npm run new -- analysis some-service
```

글 상단의 설정 값은 이런 모양이다.

```yaml
title: "제목"
status: 진행중
draft: true
```

`draft: true`인 글은 개발 서버에서만 보이고 배포 빌드에서는 빠진다.
